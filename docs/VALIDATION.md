# Package validation

The following checks were completed during preparation without provider calls:

- Frozen-label SHA-256 and exact denominators passed.
- Coverage-matched null reproduced 19/101 observed unsafe exposure, 0.330
  random-withholding exposure, and margin CI [0.104, 0.175].
- Task-clustered sensitivity regenerated the reference CSV byte for byte.
- Archived ablation and receipt-replay outcomes reaggregated to the supplied
  statistics. This checks archived outcomes, not absent raw receipts.
- Optional analysis figure redraw completed using the included tables.
- Structural dry-run emitted 20 placeholder bundles (5 tasks x 4 conditions).
  These are schema checks, not new performance evidence.
- Two raw-input entry points exited before writes when raw inputs were absent;
  supplied statistics remained unchanged.
- Prepared text files were scanned for known author identifiers, local host
  paths, original repository links, credential-shaped strings, and private keys.
- ZIP archives use normalized timestamps and permissions and contain no Git
  history, environment files, build logs, caches, or internal provenance maps.

The manuscript and its LaTeX sources remain separate. Packaging neither
validates legal correctness nor reconstructs the complete historical study.
